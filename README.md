# 五代十國與北宋中央集權互動小測

一個以繁體中文製作的互動歷史複習網站，內容包括：

- 15 道單項選擇題、12 道填空題及 6 組職務／措施配對
- 每題完成後才解鎖下一題，交卷前可返回修改答案
- 完成最後一題後顯示 33 分總分、各題型得分與答案解析
- 可不限次數重新作答，支援手機版介面

## 使用方式

直接開啟 `index.html`，或瀏覽本專案的 GitHub Pages 網站。

本網站為純靜態頁面，使用原生 HTML、CSS、JavaScript 和 Google Fonts，不需要安裝或建置。

作答時只顯示進度，不會提前揭曉答案。完成第 33 題後按「完成並查看總分」，即可進入成績版面並展開逐題答案；按「重新作答」會清除本輪答案。

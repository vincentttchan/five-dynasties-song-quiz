# 五代十國與北宋中央集權互動小測

一個以繁體中文製作的互動歷史複習網站，內容包括：

- 15 道單項選擇題，完成全卷後統一顯示分數與解析
- 12 道填空題及 6 組職務／措施配對
- 3 道簡答思考題與參考答案
- 題號跳轉、作答進度、交卷前修改答案、無限次重做與手機版介面

## 使用方式

直接開啟 `index.html`，或瀏覽本專案的 GitHub Pages 網站。

本網站為純靜態頁面，使用原生 HTML、CSS、JavaScript 和 Google Fonts，不需要安裝或建置。

完成全部題目後按「完成並對答案」，才會顯示選擇題及填空配對的成績與解析。簡答題供學生對照參考答案自行檢視；按「重新作答」即可清除整份試卷並再次練習。
